## **Step 1: Create GitHub Account** (1 minute)

1. Go to: **https://github.com**
2. Click **"Sign up"** (top-right)
3. Enter:
   - Email address (use your professional email)
   - Password
   - Username (example: `drkhatib` or `drkhatibhomoeopathy`)
4. Verify you're human
5. Click **"Create account"**
6. Verify your email

✅ **Done!** You now have a GitHub account.

---

## **Step 2: Create Repository** (1 minute)

1. After logging in, click the **"+"** icon (top-right corner)
2. Click **"New repository"**

3. Fill in:
   - **Repository name:** `website` or `dr-khatib-homoeopathy`
   - **Description:** "Dr. Khatib Homoeopathy Website"
   - **Public** (must select this - it's free)
   - **DO NOT** check any boxes below
   
4. Click **"Create repository"** (green button at bottom)

✅ **Done!** Repository created.

---

## **Step 3: Upload Your Files** (2 minutes)

1. You'll see a page with options. Click: **"uploading an existing file"**

2. **Drag and drop** OR click "choose your files":
   - `index.html`
   - `styles.css`
   - `script.js`
   - `favicon.svg`
   
   All files are in: `C:\Users\mrlol\OneDrive\Desktop\Algorism\Doctor Malik\`

3. Wait for upload to complete (green checkmarks appear)

4. Scroll to bottom, click **"Commit changes"** (green button)

✅ **Done!** Files uploaded.

---

## **Step 4: Enable GitHub Pages** (1 minute)

1. Click **"Settings"** (top menu of your repository)

2. Scroll down left sidebar, click **"Pages"** (under "Code and automation")

3. Under "Build and deployment":
   - **Source:** Select "Deploy from a branch"
   - **Branch:** Select "main" (or "master" if that's shown)
   - **Folder:** Select "/ (root)"

4. Click **"Save"**

5. You'll see: "Your site is ready to be published at..."

✅ **Done!** GitHub Pages is enabled.

---

## **Step 5: Get Your Website URL** (30 seconds)

1. Wait 2-5 minutes (GitHub is building your site)

2. Refresh the Settings → Pages page

3. You'll see a box at top with your URL:
   ```
   ✅ Your site is live at https://YOUR-USERNAME.github.io/website/
   ```

4. **Click the URL** to view your live website! 🎉

## 📞 **Support:**

**Common Issues:**

**Q: Website not loading after 5 minutes?**
- Clear browser cache (Ctrl + Shift + Delete)
- Try incognito mode
- Wait up to 10 minutes

**Q: Files uploaded but site shows 404?**
- Make sure file is named `index.html` (not `Index.html`)
- Check if GitHub Pages is enabled
- Branch should be `main` or `master`

**Q: Want to change something?**
- Just edit the file on GitHub
- Click pencil icon → Make changes → Commit
- Wait 2-3 minutes for auto-update

**Q: How to delete and start over?**
- Go to Settings → Scroll to bottom
- Click "Delete this repository"
- Start from Step 2 again
